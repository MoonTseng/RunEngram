# Automatic Learning Smoke Evidence

The simulated source task could not consume a Notion requirement directly.
The accepted recovery route was:

1. use the existing `one-flow` `notion-to-prd` step;
2. produce readable PRD Markdown;
3. continue analysis from that artifact.

This guidance is scoped to requirements supplied as Notion links. It is not a
general rule for local Markdown or other document sources.
